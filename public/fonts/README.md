# Fonts

`fraunces-latin-wght.woff2` — Fraunces (variable, `wght` 300–600, Latin subset).

- Source: Google Fonts, https://fonts.google.com/specimen/Fraunces (project: https://github.com/undercasetype/Fraunces)
- Licence: SIL Open Font License 1.1, see `OFL.txt` in this folder.
- Self-hosted on purpose: no third-party font requests, and it can be cached for offline use.

`fraunces-latin-wght-italic.woff2` — Fraunces Italic (variable, `wght` 300–600, Latin subset), same source and licence. Only loaded if italic unit labels are chosen (`--label-style: italic`); delete it if regular labels are kept.
